# Screen content

The default aurora is generated by `src/screen-content.js`. It is a static GPU shader, not a raster image or a real Sphere show recording.

The shader samples the normalized 3D direction from the reconstructed screen centre. Broad green, blue and violet ribbons are smooth functions of that direction. It does not use the flat image longitude/latitude UV map, so there is no image seam or polar squeeze of a character face. Viewing from different seats still changes perspective, as it would for a real physical screen.

The artwork remains static for seated VR. Its background is brighter than the dark, matte enclosure outside the LED. The existing screen boundary, geometry and VR UI layering are retained.

The earlier AI-generated Chiikawa illustration was removed from the current site because stretching a flat character illustration over the spherical cap distorted it. It remains only in Git history. Optional Earth, stars and diagnostic UV grid modes are generated locally in code.
