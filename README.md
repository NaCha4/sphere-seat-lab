# Sphere Seat Lab

[웹 열기](https://nacha4.github.io/sphere-seat-lab/) · Research 09 · 2026-10-21

Sphere Las Vegas 고정 객석에서 아이디어를 탐색하는 수업용 WebXR 뷰어. **준공 CAD 복제본이 아니며 실제 시야의 정량 검증은 아직 불가능하다.** [조사·가정·검증 기록](RECONSTRUCTION_AUDIT.md)에 확인된 사실과 추정을 구분했다.

## 사용

- 상단 `재생 영상`에서 기존 **Chromatic Flux**와 새 **산맥의 노을**을 선택한다. 원본·V1·V2 모두 지원한다. Quest 메뉴에서는 `다음 영상`을 누른다. 버전을 바꿔도 선택한 영상과 재생 위치를 유지한다.
- 산맥의 노을은 Giuseppe Paoletti의 Pexels 4K 원본을 화면에 맞게 가공한 8초 실사 타임랩스다. 360° 촬영 영상은 아니다. [출처·라이선스·가공 정보](ASSET_NOTES.md#mountain-sunset)를 참고한다.

- 세 번째 월드 `V2 · 부채형 차광막 / 3단 영상`은 두 수평 차광막을 접고 펼치며 각 단의 곡면을 채우는 와이드 영상을 세 높이에서 재생한다. VR에서 `다음 월드 목록` → `V2 차광막`을 선택하고 `차광막 펼치기`를 누른다. [가정·조작법·한계](VARIATIONS.md)를 확인한다.

- `객석 월드`에서 원본과 `V1 · 리클라이너 / 시청 우선 배치`를 선택한다. VR 메뉴 상단에서도 전환할 수 있으며 같은 구역의 대응 위치와 영상 재생 상태를 유지한다.
- V1은 좌석 폭 0.90m, 중심 간격 1.02m의 리클라이너 4,086석을 배치하고, 모든 층의 깊은 단·통로·곡률과 관람 방향을 함께 조정한다. [설계 가정과 비교 방법](VARIATIONS.md)을 확인한다.
- 웹의 `209 구역` / `210 구역` 또는 VR `209 ↔ 210`으로 사례 좌석에 이동한다. 관객을 켜면 원본/V1의 좌석 수, 방향 차이와 머리 가림 표본 수를 비교한다.

- 구역, 행, 행 안의 위치를 선택하고 1인칭으로 둘러본다. 순번은 실제 티켓 번호가 아니다.
- 전체 구조에서 좌석을 누르거나, Quest 3 브라우저의 `VR 시작` 후 포인터로 가리킨다. 민트색 미리보기를 확인하고 트리거/핀치로 이동한다.
- VR 메뉴는 **오른손 A / 왼손 X** 버튼으로 켜고 끈다. 버튼을 누르고 있어도 한 번만 전환되며, 다시 켜면 현재 보는 방향 앞에 표시된다. 메뉴를 숨겨도 좌석 선택과 이동은 가능하다.
- 기본 영상은 회전하는 네온 궤도·유동 등고선·확산 링으로 구성한 20초 Chromatic Flux 모션그래픽이다. 이 영상의 원본·V1 버전은 360° 구면용, V2 버전은 각 단 비율의 3단 와이드 영상이다. PC의 `영상 일시정지` 또는 VR 메뉴의 `영상 재생/정지`로 제어한다. 무음 반복이며, 정지 화면으로 변경하면 영상도 멈춘다.
- `관객 채우기`는 현재 위치를 비우고 다른 일반 좌석 위치에 인체 모형을 표시한다.
- 고정 구조가 기본이다. `U2 2023 무대 표시`로 도면을 참고한 공연 설치를 별도로 켤 수 있다.
- 오른쪽 위 정보 버튼에 출처와 모델 한계가 있다. 모션그래픽은 실제 공연이 아닌 자체 제작 영상이다.

## 데이터와 구조

공식 Ticketmaster의 서로 다른 두 공연에서 숫자행/행별 수량을 대조해 39개 구역·13,830개 일반 위치를 반영했다. WC 178개, 가변 객석, 스위트 등은 별도 범위이며 공간 좌표를 임의 생성하지 않았다. 명목 수용 인원 17,385를 맞추기 위해 의자를 추가하지 않는다.

2023 U2 작업 도면의 축척과 하부 윤곽을 적용했다. 17개 추적점, 약 0.873m 행 깊이, 두 주요 통로, 발코니 전면, 검은 후방 천장, 계단형 LED 경계를 반영했다. 원본 픽셀과 환산 기준은 `src/data/production-plan.json`에 있다.

상층 평면·높이는 기존 자료의 추정을 유지한다. 가려진 하부 뒷열, 좌석 배분, 구조 두께와 정확한 패널 경계도 미확인이다. 시야 가림·거리·각도는 이 가정의 계산 결과이며 현장 검증값이 아니다.

객석 옆면·후면·하부를 닫힌 입체로 만들고, 구역 사이 계단과 지붕 접합부를 보완했다. 300번대 추정 높이는 하층 관객과의 간섭을 제거하기 위해 1.5m 높였다. 객석/계단 74개 입체의 폐쇄성, 좌석 바닥 지지, 모든 좌석의 눈·머리 위치를 검사한다.

## 개발

```sh
npm ci
npm test
npm run dev
npm run build
```

Three.js / Vite. `docs/`에 GitHub Pages용 상대 경로 정적 파일을 생성한다. 실행 중 외부 CDN이 필요하지 않다. Quest 3 실기 확인은 별도로 필요하다.

## 공개 범위

공개 저장소에는 웹 코드·자체 문서·수치 데이터·자체 제작 영상과 사용 허가를 확인한 풍경 영상의 가공본을 포함한다. 강의 자료·논문·녹취록·제3자 원본 도면/사진/PDF는 포함하지 않는다. 풍경 영상의 원본 다운로드도 공개하지 않는다. GitHub Pages는 `codex/sphere-baseline` 브랜치의 `/docs`에서 제공한다.
