# Sphere Seat Lab

공개 자료를 바탕으로 재구성한 Las Vegas Sphere의 좌석별 관람 시야를 살펴보는 수업용 Three.js / WebXR 사이트입니다.

- 웹 체험: <https://nacha4.github.io/sphere-seat-lab/>
- 공개 웹 소스: <https://github.com/NaCha4/sphere-seat-lab>
- 배포 브랜치: `codex/sphere-baseline`, 배포 폴더: `/docs`

수업 자료를 담은 원래 비공개 저장소와 공개 웹 저장소는 별도 이력을 사용합니다. 공개 저장소에는 이 웹 프로젝트 파일만 포함합니다.

## 실행

```sh
npm ci
npm run dev
npm test
npm run build
```

빌드 결과는 `docs/`에 생성됩니다. GitHub Pages의 배포 브랜치에서 `/docs`를 소스로 선택할 수 있습니다. Vite의 상대 경로 빌드로 프로젝트 하위 URL에서도 동작합니다. 서버, 데이터베이스, API 키는 사용하지 않습니다.

## 사용

- PC: 구역 지도 또는 100/200/300/400 탭 → 구역·행·좌석 선택. 마우스 드래그로 시선 이동, 휠로 확대, R로 초기화.
- 전체 구조: 반투명 스크린과 외피 안에서 회전·확대하고 좌석을 클릭해 이동.
- Meta Quest 3: **HTTPS** 사이트를 Quest Browser에서 열고 **VR 시작**. 좌석을 가리키면 민트색으로 빛나고 패널에 구역·행·번호가 표시됩니다. 컨트롤러 트리거 또는 손 추적 핀치로 이동을 확정합니다. 스틱 좌우는 좌석, 상하는 행을 이동합니다. VR 패널에서 구역·층 변경과 종료가 가능합니다. 패널과 포인터는 LED 스크린 뒤에 가려지지 않도록 별도 표시 순서를 사용합니다.
- 기본 스크린은 밝은 치이카와 팬 일러스트입니다. 기존 지구·격자·별빛 화면으로 전환할 수 있습니다. 생성 방식과 프롬프트는 [ASSET_NOTES.md](ASSET_NOTES.md)에 기록했습니다.
- 카메라 버튼은 3D 화면을 PNG로 저장합니다. 링크 버튼으로 현재 좌석 URL을 복사할 수 있습니다.
- 100층 앞쪽 가변 객석 옵션은 공연마다 달라지는 앞쪽 1–11행을 표시합니다.

## 재현 범위

공식 외피 크기·스크린 정점 높이, 4개 객석 층과 구역 체계, 상부로 갈수록 좁아지는 객석 형상, 100층 후방의 상부 가림을 반영했습니다. **실측 CAD/BIM 또는 실제 티켓 좌석 좌표가 아닙니다.** 행 간격·단높이·곡면 축·무대 치수·개별 좌석 번호는 시각 자료에 맞춘 추정입니다. 모델의 숫자 좌석은 탐색용 식별자입니다. 정확한 재현 범위와 근거는 [MODEL_NOTES.md](MODEL_NOTES.md)에 기록했습니다.

이 사이트는 Sphere Entertainment와 관계없는 독립적인 교육용 재구성입니다. 실제 공연 영상, 원본 건축 도면, 관람객 사진은 재배포하지 않습니다. 정적 배포에는 수업 PDF, 녹취록 및 연구용 다운로드가 포함되지 않습니다.

## 검증

`npm test`는 구역 체계, 좌석 식별자·좌표·외피 경계, 공유 링크 입력, 가변 객석의 좌표 보존을 확인합니다. 실제 모델의 광선 교차 검사로 100층 뒤쪽에서 상부 화면이 가려지고 중앙 200층에서는 보이는지도 확인합니다. 이 검사는 브라우저·GPU·VR 실기기 검사를 대체하지 않습니다. `npm run build`는 소스와 로컬 라이브러리만 묶어 외부 CDN 없이 배포 파일을 생성합니다. 실제 Quest에서의 프레임률·컨트롤러·VR 세션은 기기 테스트가 필요합니다.
