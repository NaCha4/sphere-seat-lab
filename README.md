# Sphere Seat Lab

[웹 열기](https://nacha4.github.io/sphere-seat-lab/) · Research 04 · 2026-10-20

Sphere Las Vegas 고정 객석에서 아이디어를 탐색하는 수업용 WebXR 뷰어. **준공 CAD 복제본이 아니며 실제 시야의 정량 검증은 아직 불가능하다.** [조사·가정·검증 기록](RECONSTRUCTION_AUDIT.md)에 확인된 사실과 추정을 구분했다.

## 사용

- 구역, 행, 행 안의 위치를 선택하고 1인칭으로 둘러본다. 순번은 실제 티켓 번호가 아니다.
- 전체 구조에서 좌석을 누르거나, Quest 3 브라우저의 `VR 시작` 후 포인터로 가리킨다. 민트색 미리보기를 확인하고 트리거/핀치로 이동한다.
- VR 메뉴는 **오른손 A / 왼손 X** 버튼으로 켜고 끈다. 버튼을 누르고 있어도 한 번만 전환되며, 다시 켜면 현재 보는 방향 앞에 표시된다. 메뉴를 숨겨도 좌석 선택과 이동은 가능하다.
- `관객 채우기`는 현재 위치를 비우고 다른 일반 좌석 위치에 인체 모형을 표시한다.
- 고정 구조가 기본이다. `U2 2023 무대 표시`로 도면을 참고한 공연 설치를 별도로 켤 수 있다.
- 오른쪽 위 정보 버튼에 출처와 모델 한계가 있다. 오로라는 실제 공연이 아닌 구면용 절차 생성 콘텐츠다.

## 데이터와 구조

공식 Ticketmaster의 서로 다른 두 공연에서 숫자행/행별 수량을 대조해 39개 구역·13,830개 일반 위치를 반영했다. WC 178개, 가변 객석, 스위트 등은 별도 범위이며 공간 좌표를 임의 생성하지 않았다. 명목 수용 인원 17,385를 맞추기 위해 의자를 추가하지 않는다.

2023 U2 작업 도면의 축척과 하부 윤곽을 적용했다. 17개 추적점, 약 0.873m 행 깊이, 두 주요 통로, 발코니 전면, 검은 후방 천장, 계단형 LED 경계를 반영했다. 원본 픽셀과 환산 기준은 `src/data/production-plan.json`에 있다.

상층 평면·높이는 기존 자료의 추정을 유지한다. 가려진 하부 뒷열, 좌석 배분, 구조 두께와 정확한 패널 경계도 미확인이다. 시야 가림·거리·각도는 이 가정의 계산 결과이며 현장 검증값이 아니다.

객석 옆면·후면·하부를 닫힌 입체로 만들고, 구역 사이 계단과 지붕 접합부를 보완했다. 300번대 추정 높이는 하층 관객과의 간섭을 제거하기 위해 1.5m 높였다. 객석/계단 74개 입체의 폐쇄성, 좌석 바닥 지지, 모든 좌석의 눈·머리 위치를 검사한다.

## 개발

```sh
npm test
npm run dev
npm run build
```

Three.js / Vite. `docs/`에 GitHub Pages용 상대 경로 정적 파일을 생성한다. 실행 중 외부 CDN이 필요하지 않다. Quest 3 실기 확인은 별도로 필요하다.

## 공개 범위

공개 저장소에는 웹 코드·자체 문서·수치 데이터만 포함한다. 강의 자료·논문·녹취록·제3자 원본 도면/사진/PDF는 포함하지 않는다. GitHub Pages는 `codex/sphere-baseline` 브랜치의 `/docs`에서 제공한다.
